Карта курса

Каждая тема опирается на предыдущие, поэтому лучше идти по порядку:

Матрицы (что это, сложение, умножение) → Определители (2×2 → 3×3 → миноры → любой размер) → Обратная матрица (использует определитель и миноры) → Системы уравнений (используют всё сразу).

Язык выделений везде одинаковый: рамка — строка / первая матрица, серая заливка — столбец / «плюс» / верно, пунктир — «минус» / вычёркнутое / что убираем, залитая плашка — результат.

★

Как учиться, чтобы реально запомнить

Этот файл построен на приёмах, которые проверены исследованиями памяти. Зная их, ты будешь учиться в 2–3 раза эффективнее.

1. Сначала угадай
В разборах включи «угадывать»: перед каждым ключевым числом тебя спросят ответ. Попытка вспомнить укрепляет память сильнее, чем перечитывание (эффект тестирования). Даже ошибка помогает — ты потом лучше запомнишь правильный ответ.
2. Спрашивай «почему»
У каждого правила есть блок «Почему так?». Правило, которое ты понял, вспоминается само: его можно вывести заново. Правило, которое ты просто зазубрил, путается (например, где минус, а где плюс).
3. Подсказки убираются
Порядок: посмотри разбор → реши «по шагам» (тренажёр спрашивает каждое число) → реши сам сразу ответ. Это называют «затухающие примеры»: от готового решения к самостоятельному.
4. Вперемешку
В тренажёре можно выбрать сразу несколько тем. Так сложнее, но на контрольной ты сам должен понять, какой метод нужен — и именно этот навык тренируется при перемешивании.
5. Повторение с паузами
Карточки сами покажут вопрос через 1, 3, 7 и 16 дней. Повторить в момент, когда начинаешь забывать, — самый сильный способ запомнить надолго.
6. Цвет + картинка + слова
Каждое правило есть в трёх видах: формула, картинка с подсветкой и фраза-запоминалка. Мозг лучше держит то, что закодировано несколькими способами.
7. Ищи ошибку
Тренажёр узнаёт типичные ошибки (забыл минус, не транспонировал, сложил вместо вычитания) и говорит, какая именно. Знать «ловушку в лицо» — лучший способ в неё не попасть.
Маршрут на один день (≈ 60 мин)
  1. Прочитай одну тему (10 мин), разбор — с угадыванием.
  2. 10 задач этой темы в тренажёре.
  3. 5 задач вперемешку со старыми темами.
  4. Карточки — 5 минут.
  5. Раз в неделю — мини-контрольная.
01

Что такое матрица и как читать aᵢⱼ

Таблица чисел. И у каждого числа есть «адрес».

Простыми словами

Матрица — это прямоугольная таблица чисел в скобках. Как таблица в Excel, только без подписей.

← 2 строки, 3 столбца. Размер пишут 2×3 («два на три»): сначала строки, потом столбцы.

Каждое число — элемент aij: i — номер строки (сверху вниз), j — номер столбца (слева направо). Здесь a13 = 9, a21 = 5.

Квадратная матрица — строк столько же, сколько столбцов (2×2, 3×3…). Это число называют порядком. Иначе матрица прямоугольная.

Почему важен порядок индексов?
a23 и a32 — разные клетки! a23 — строка 2, столбец 3; a32 — строка 3, столбец 2. Договорились всегда писать «строка, потом столбец», чтобы все читали одинаково. Этот же порядок — в размере m×n и во всех формулах дальше.
Запоминалка
Как в кинотеатре: «ряд 2, место 3» — это a23. Сначала ряд (строка, горизонтально →), потом место (столбец, вертикально ↓).
Особые матрицы
Нулевая Oвсе нули:
Единичная Eна диагонали 1, остальное 0: — работает как число 1
Треугольнаяпод (или над) диагональю — нули
Строка / столбец1×n или n×1
Равенство матриц
A = B, если одинаковый размер и все элементы на одинаковых местах равны. Матрицы 2×3 и 3×2 никогда не равны, даже из одних и тех же чисел.

Главная диагональ — от a₁₁ вниз-вправо ↘. Побочная — из правого верхнего угла вниз-влево ↙.
02

Транспонирование Aᵀ

Строки становятся столбцами.

Простыми словами

1-я строка → 1-й столбец, 2-я строка → 2-й столбец и т.д. Размер «переворачивается»: m×n → n×m.

→
Что происходит на самом деле
Элемент с адресом (i, j) переезжает на адрес (j, i): aij → aji. У квадратной матрицы это зеркальное отражение относительно главной диагонали — сама диагональ стоит на месте.
Свойства (пригодятся позже)
(Aᵀ)ᵀ = A — дважды отразить = вернуть.   (A + B)ᵀ = Aᵀ + Bᵀ.   (AB)ᵀ = BᵀAᵀ — порядок меняется!   |Aᵀ| = |A|.
03

Сложение и умножение на число

Самое простое: клеточка к клеточке.

Простыми словами

Сложение: только для матриц одного размера. Складываем числа на одинаковых местах.

+=

Умножение на число k: умножаем каждый элемент. −A — у всех элементов меняем знак. A − B = A + (−B).

Ловушка: матрица ≠ определитель
Матрицу на число — умножаются все элементы. Определитель на число — умножается только одна строка (или столбец). Поэтому |2A| для матрицы 3×3 = 2³·|A| = 8|A|, а не 2|A|.
А почему нельзя сложить 2×2 и 2×3?
У «лишнего» столбца нет пары — непонятно, с чем его складывать. Поэтому ответ в такой задаче: «не определено».
Свойства как у обычных чисел
A + B = B + A; (A + B) + C = A + (B + C); A + O = A; A + (−A) = O; k(A + B) = kA + kB; (k + m)A = kA + mA; 0·A = O.
Приём против ошибок в A − 3B
Сначала посчитай −3B целиком (знак «приклеен» к числу), а потом только складывай. Ошибки со знаками почти исчезают.
04

Умножение матриц: строка × столбец

Главное правило всей темы.

Простыми словами

Шаг 0 — можно ли? Пишем размеры рядом: 3×2 · 2×4 → 3×4. Внутренние числа должны совпасть, внешние дают размер ответа.

Шаг 1 — как? Клетка ответа cij = i-я строка A × j-й столбец B: перемножаем пары по порядку (1-е с 1-м, 2-е со 2-м…) и складываем.

cij = ai1b1j + ai2b2j + … + ainbnj
Почему такое странное правило? (история про магазин)

Аня купила 2 кофе и 1 булку, Боря — 0 кофе и 4 булки. В магазине 1 кофе стоит 100, булка 40; в магазине 2 — 120 и 30.

·=

Сколько Аня заплатит в магазине 1? Её покупки (строка) × цены магазина 1 (столбец): 2·100 + 1·40 = 240. Вот и «строка × столбец»! А размеры должны совпасть, потому что у каждого товара должна быть цена.

AB ≠ BA
Для чисел 2·3 = 3·2, а для матриц — в общем случае нет. Иногда BA даже не существует. Поэтому множители в матричных выражениях нельзя переставлять: (A + B)² = A² + AB + BA + B², а не A² + 2AB + B².
Ещё сюрприз: произведение двух ненулевых матриц может быть нулевой матрицей.
Свойства
A·E = E·A = A (единичная — как 1).  (AB)C = A(BC).  A(B + C) = AB + AC.  |AB| = |A|·|B|.
Степень: A² = A·A, A³ = A²·A — только для квадратных и не «каждый элемент в квадрат». В многочлене число превращается в число·E: f(A) = A² − 3A + 2 → A² − 3A + 2E.
Запоминалка
«Лежачий × стоячий»: строка лежит, столбец стоит. Палец левой руки ведёт по строке →, палец правой — по столбцу ↓, одновременно.
05

Определитель 2×2

Одно число, которое многое говорит о матрице.

Простыми словами

Определитель (детерминант, |A|, det A, Δ) — это число, которое считают по квадратной матрице. У прямоугольных его нет вообще.

=a·d − b·c«главная диагональ минус побочная»

Пример: = 1·2 − 4·5 = 2 − 20 = −18.

Прямые черточки | | — это число. Скобки ( ) — это таблица. Не путай!

Зачем он нужен и откуда минус?

Представь, что строки матрицы — это две стрелки на плоскости. Они натягивают параллелограмм. Определитель = площадь этого параллелограмма со знаком.

  • Поменяли строки местами → фигура «перевернулась» → знак поменялся. Формула ad − bc именно так и устроена: cb − da = −(ad − bc).
  • Строки пропорциональны (стрелки на одной прямой) → площадь 0 → Δ = 0.
  • Δ = 0 значит: матрица «сплющивает» плоскость в линию, информация теряется → обратной матрицы нет (часть 3) и система не имеет единственного решения (часть 4).
А почему не ad + bc?
Тогда у матрицы с двумя одинаковыми строками (2 3; 2 3) получилось бы 6 + 6 = 12. Но две одинаковые стрелки лежат на одной прямой — площадь должна быть 0. Только с минусом: 6 − 6 = 0 ✓.
Запоминалка
«Вниз — плюс, вверх — минус»: стрелка ↘ (главная) идёт со знаком +, стрелка ↗ (побочная) — со знаком −. И всегда сначала главная.

07

Определитель 3×3: правило треугольников

Шесть произведений: три с «+», три с «−».

Простыми словами

Определитель 3×3 = сумма 6 произведений по 3 числа. Какие тройки брать — показывают картинки:

(a₁₁a₂₂a₃₃ + a₁₂a₂₃a₃₁ + a₁₃a₂₁a₃₂) − (a₁₃a₂₂a₃₁ + a₁₁a₂₃a₃₂ + a₁₂a₂₁a₃₃)

Как найти треугольник: одна его сторона параллельна диагонали (главной для «плюсовых», побочной для «минусовых»), а третья вершина — в противоположном углу.

Проверка любой тройки: в ней ровно одно число из каждой строки и одно из каждого столбца. Если две клетки в одной строке — тройка неправильная.

Откуда берутся эти 6 произведений?
Разложим по первой строке (тема 9): Δ = a₁₁·(a₂₂a₃₃ − a₂₃a₃₂) − a₁₂·(a₂₁a₃₃ − a₂₃a₃₁) + a₁₃·(a₂₁a₃₂ − a₂₂a₃₁). Раскроем скобки — получится ровно 6 слагаемых, 3 с «+» и 3 с «−». Правило треугольников — это просто картинка этих 6 слагаемых, чтобы не раскрывать скобки каждый раз.
Если треугольники путаются — правило Саррюса

Допиши справа первые два столбца ещё раз. Тогда все «плюсовые» тройки — это три параллельные диагонали вниз-вправо, а «минусовые» — три диагонали вниз-влево. Результат тот же самый.

Ошибка №1: минус перед скобкой
Δ = (плюсы) − (минусы). Если сумма минусов отрицательная, например −7, то −4 − (−7) = −4 + 7 = 3, а не −11. Считай сначала две суммы отдельно, а вычитай в самом конце.
И ещё: правило треугольников работает только для 3×3. Для 4×4 — разложение или треугольный вид.
Мини-игра: собери треугольник

Кликни 3 клетки, которые входят в нужное произведение. Повторяй, пока не будешь делать это не задумываясь.

08

Минор Mᵢⱼ и алгебраическое дополнение Aᵢⱼ

Ключ к определителям любого размера и к обратной матрице.

Минор Mᵢⱼ
Вычёркиваем строку i и столбец j (те, где стоит элемент aij). То, что осталось, — определитель на размер меньше. Его значение и есть минор.
→M₁₂ = −1·2 − 1·1 = −3
Алгебраическое дополнение Aᵢⱼ
Aij = (−1)i+j · Mij
Тот же минор, но со знаком. i + j чётное → «+» (минор как есть). Нечётное → «−» (меняем знак минора).
A₁₂ = (−1)1+2·(−3) = (−1)·(−3) = 3.
Шахматка знаков — чтобы не считать (−1)ⁱ⁺ʲ
+−+−−+−++−+−−+−+
В левом верхнем углу всегда «+», дальше чередуется, как на шахматной доске. Например, a₂₃: 2 + 3 = 5 нечётное → «−», и в шахматке на месте (2, 3) тоже «−».
Зачем вообще знак?
Когда раскладываем определитель по строке, слагаемые идут с чередующимися знаками: + a₁₁M₁₁ − a₁₂M₁₂ + a₁₃M₁₃. Чтобы не помнить, где минус, знак «прячут» внутрь: Aij = ±Mij. Тогда формула становится простой суммой: Δ = a₁₁A₁₁ + a₁₂A₁₂ + a₁₃A₁₃. А чередуются знаки потому, что каждая перестановка соседних столбцов меняет знак (свойство 2).
Запоминалка
Минор — голый, дополнение — одетое (в знак). Сначала вычеркни и посчитай, потом «одень» знаком из шахматки.
09

Разложение по строке или столбцу

Универсальный способ: большой определитель → несколько маленьких.

Простыми словами
Δ = ai1Ai1 + ai2Ai2 + … + ainAin
Берём любую строку (или столбец). Каждый её элемент умножаем на его алгебраическое дополнение и всё складываем. Знаки — из шахматки: по 1-й строке + − +, по 2-й − + −.
Почему можно по любой линии?
Любую строку можно «переставить наверх» соседними перестановками — каждая меняет знак. Отсюда и шахматка: она просто учитывает эти смены знака. Поэтому ответ всегда один и тот же (свойство 7).
Свойство 8: если умножить элементы одной строки на дополнения другой строки, получится 0 (это как определитель с двумя одинаковыми строками). Понадобится для обратной матрицы.
Стратегия
Ищи нули! Ноль × что угодно = 0 — это слагаемое исчезает, и его минор даже не надо считать. Для 4×4 без нулей пришлось бы считать четыре 3×3, а каждый ноль убирает один из них.
10

Треугольный вид, определители 4×4 и n×n

Делаем нули под диагональю — и просто перемножаем диагональ.

Простыми словами

Если под главной диагональю одни нули, то определитель = произведение чисел на диагонали. Нули делаем свойством 6: из строки вычитаем верхнюю строку, умноженную на нужное число.

k = (число, которое убиваем) / (ступенька на диагонали)

Проверка: a − k·p = a − (a/p)·p = 0 ✓.

Алгоритм
  1. Если a₁₁ = 0 — поменяй строки (знак Δ меняется!). Лучше, чтобы a₁₁ = 1 или −1 — тогда множители целые.
  2. Обнули весь 1-й столбец под a₁₁ (каждую строку — своим k).
  3. Забудь 1-ю строку и 1-й столбец, повтори то же для оставшейся матрицы.
  4. Ответ = произведение диагонали × (−1 за каждую перестановку) × (вынесенные множители).
Почему треугольный = произведение диагонали?
Раскладываем по 1-му столбцу: там только a₁₁, остальные нули → Δ = a₁₁·(минор). Минор тоже треугольный → a₂₂·(ещё меньше)… Итог: a₁₁·a₂₂·…·aₙₙ.
Метод понижения порядка (другой путь)
Не обязательно доводить до треугольника. Достаточно сделать в одной строке (или столбце) все нули, кроме одного, — и разложить по ней. 4×4 превращается в один 3×3. Пример из лекции: в строках 1 и 3 последние три числа одинаковые → С₁ − С₃ = (3 0 0 0) → Δ = 3·(определитель 3×3).

Обратная 2×2: почему числа меняются местами и откуда минус

Разбираем именно тот пример со скриншота: A = (3 4; 1 2) → A* = (2 −4; −1 3). Это не фокус — сейчас станет видно, откуда каждая цифра.

Ответ в двух фразах

«Быстрое правило» — это сокращённая общая формула A⁻¹ = (1/|A|)·A*, где A* — таблица алгебраических дополнений, повёрнутая (транспонированная).

У матрицы 2×2, если вычеркнуть строку и столбец, остаётся одно число из противоположного угла → поэтому 3 и 2 «меняются местами». А минус у 4 и 1 — это знак из шахматки (+ −; − +): на местах (1,2) и (2,1) сумма индексов нечётная.

Медленно, по одной клетке (A = (3 4; 1 2))
КлеткаВычёркиваем её строку и столбецОстаётсяЗнак (шахматка)Дополнение
a₁₁ = 32+ (1+1 = 2)A₁₁ = 2
a₁₂ = 41− (1+2 = 3)A₁₂ = −1
a₂₁ = 14− (2+1 = 3)A₂₁ = −4
a₂₂ = 23+ (2+2 = 4)A₂₂ = 3
Ставим дополнения на свои места:транспонируем →

Смотри, что получилось по сравнению с A = (3 4; 1 2):

  • Главная диагональ: 3 и 2 поменялись местами — потому что у 3 «напротив» стоит 2, а у 2 — 3.
  • Побочная диагональ: 4 и 1 остались на своих местах, но получили минус. (У 4 напротив стоит 1, у 1 — 4; дополнения сначала «поменялись», а транспонирование вернуло их обратно. Минус — из шахматки.)

Последний шаг: |A| = 3·2 − 4·1 = 2, делим всё на 2: A⁻¹ = ½·(2 −4; −1 3) = (1 −2; −½ 3/2).

А почему вообще это даёт обратную? (проверка умножением)

Умножим A на A* в общем виде:

(a b; c d) · (d −b; −c a) = ( a·d + b·(−c)    a·(−b) + b·a ;   c·d + d·(−c)    c·(−b) + d·a )
= ( ad − bc    −ab + ab ;   cd − cd    ad − bc ) = ( |A|   0 ;   0   |A| ) = |A|·E
  • Перестановка a ↔ d нужна, чтобы на диагонали получилось ad − bc, то есть определитель.
  • Минус у b и c нужен, чтобы вне диагонали произведения уничтожили друг друга: −ab + ab = 0. Без минуса было бы ab + ab = 2ab ≠ 0.
  • Деление на |A| превращает |A|·E в E. Как с числами: 5 · ⅕ = 1. Если |A| = 0 — делить нельзя, обратной нет.
Лаборатория «а если по-другому?» — проверь сам

Меняй числа A и выбирай вариант. Справа — A, умноженная на «кандидата». Обратная получится только если результат = (число)·E.

Запоминалка
«Главные — переезжают, побочные — меняют знак, все — делятся».
Главная диагональ: числа меняются местами. Побочная: остаются на месте, но с минусом. Всё делим на |A|. И обязательно проверка: A·A⁻¹ = E.

Обратная матрица 3×3 (и любая)

A⁻¹ = (1/|A|)·A*. Тот же алгоритм, что и для 2×2, только дополнений 9.

5 шагов
  1. Посчитай |A|. Ноль → обратной нет, стоп.
  2. Посчитай 9 алгебраических дополнений Aij (вычеркнул → 2×2 → знак по шахматке).
  3. Запиши их таблицей и транспонируй — это A* (присоединённая). Дополнение Aij встаёт на место (j, i).
  4. Раздели каждый элемент на |A|.
  5. Проверь: A·A⁻¹ = E.
Почему транспонируем?
При умножении A·A* строка i матрицы A умножается на столбец j матрицы A*. После транспонирования этот столбец — это дополнения строки j.
• Если i = j: элементы строки × свои дополнения = разложение по строке = |A| (свойство 7).
• Если i ≠ j: элементы строки × чужие дополнения = 0 (свойство 8).
Итог: A·A* = |A|·E. Делим на |A| → E. Без транспонирования строки встретились бы не со «своими» дополнениями.
Запоминалка
«Определи → дополни → переверни → подели → проверь» (О-Д-П-П-П). Самая частая ошибка — забыть «переверни» (транспонировать).
Свойства обратной
A·A⁻¹ = A⁻¹·A = E;  (A⁻¹)⁻¹ = A;  |A⁻¹| = 1/|A|;  (AB)⁻¹ = B⁻¹A⁻¹ — как носки и ботинки: надеваем носки, потом ботинки, а снимаем в обратном порядке.  (Aᵀ)⁻¹ = (A⁻¹)ᵀ.
13

Когда обратной матрицы нет (вырожденная матрица, параметр)

Простыми словами

Обратная существует только если |A| ≠ 0. Матрица с |A| = 0 называется вырожденной.

Задача «при каких x нет обратной?» = «при каких x определитель равен 0?». Считаем |A| с буквой, приравниваем к нулю, решаем уравнение.

Почему при |A| = 0 обратной нет?
1) В формуле A⁻¹ = A*/|A| пришлось бы делить на 0.
2) Глубже: |A·A⁻¹| = |E| = 1, но |A·A⁻¹| = |A|·|A⁻¹| = 0·|A⁻¹| = 0. Получается 1 = 0 — противоречие. Значит, такой A⁻¹ не бывает.
3) Картинкой: матрица с |A| = 0 «сплющивает» плоскость в линию. Разные точки слипаются в одну — и «разлепить» их обратно невозможно.
Ловушка: не дели на x!
2x² − 18x = 0 → выносим: 2x(x − 9) = 0 → x = 0 или x = 9. Если поделить на x, корень x = 0 теряется (а делить на x можно только когда x ≠ 0). И не забывай отрицательные корни: x² = 9 → x = ±3.

Матричные уравнения A·X = B и X·A = B

Простыми словами

Делить матрицы нельзя. Вместо деления умножаем на обратную — с той же стороны, где стоит A:

A + X = BX = B − A
A·X = B (A слева)X = A⁻¹·B (A⁻¹ слева)
X·A = B (A справа)X = B·A⁻¹ (A⁻¹ справа)
A·X·B = CX = A⁻¹·C·B⁻¹
A·X·B·C = EX = A⁻¹·C⁻¹·B⁻¹ (снимаем «одежду» снаружи)
Почему сторона важна
A⁻¹ «уничтожает» A, только когда стоит вплотную: A⁻¹·A = E. Если A·X = B умножить на A⁻¹ справа, получится A·X·A⁻¹ — A и A⁻¹ разделены иксом и не сокращаются (ведь AB ≠ BA, переставлять нельзя).
Запоминалка
«Где A, там и A⁻¹». И всегда подставь ответ обратно — проверка занимает минуту.

Система уравнений → матрицы

Простыми словами

Систему записывают как A·X = C: A — коэффициенты, X — столбец неизвестных, C — правые части.

2x + y = 5
x − 3y = −1
⇔·=

Перемножь левую часть «строка × столбец» — получишь ровно левые части уравнений. Вот зачем умножение матриц устроено именно так!

Расширенная матрица (A | C) — коэффициенты и правые части в одной таблице, через черту. Правила записи: каждый столбец — одна переменная, нет переменной → пишем 0, «x» без числа — это 1, «−x» — это −1.

Сколько бывает решений и почему никогда «ровно два»
Каждое уравнение с двумя неизвестными — прямая. Решение — общая точка. Прямые пересекаются (1 решение), параллельны (0) или совпадают (∞). Две прямые не могут пересечься ровно в двух точках — поэтому вариантов только три.
Какой метод выбрать
КрамерКвадратная система, Δ ≠ 0, особенно 2×2 и 3×3. «Посчитал и забыл».
Обратная матрицаX = A⁻¹·C. Удобно, если A⁻¹ уже есть или правых частей много.
ГауссРаботает всегда: любой размер, даже если решений нет или их бесконечно много.

Метод Крамера

Простыми словами
x = Δx/Δ,   y = Δy/Δ,   z = Δz/Δ

Δ — определитель коэффициентов. Δx — тот же Δ, но столбец при x заменён на правые части. Аналогично Δy, Δz. Работает только при Δ ≠ 0.

Откуда эта формула (честный вывод в 3 строки)
Правые части = x·(столбец 1) + y·(столбец 2) + z·(столбец 3). Подставим это в Δx вместо 1-го столбца. По свойству 6 вычтем из него y·(столбец 2) и z·(столбец 3) — определитель не изменится, а в 1-м столбце останется x·(столбец 1). Вынесем x (свойство 4): Δx = x·Δ. Отсюда x = Δx/Δ.
Запоминалка
«Ищешь x — выгони столбец x, посади на его место ответы».

Метод Гаусса: прямой и обратный ход

Простыми словами

Прямой ход — спускаемся сверху вниз и делаем нули под «ступеньками» (как в треугольном виде определителя). Обратный ход — поднимаемся снизу вверх: из последней строки находим последнюю неизвестную, подставляем выше и т.д.

Разрешено только 3 действия (П-У-П): Переставить уравнения; Умножить уравнение на число ≠ 0; Прибавить к уравнению другое, умноженное на число.

Почему эти действия не меняют ответ?
Уравнение — это весы в равновесии. Сделаем с обеими чашами одно и то же (умножим, добавим равный груз) — равновесие сохранится. Каждое из 3 действий можно отменить (поделить обратно, вычесть обратно, переставить обратно) — значит, информация не теряется.
А почему нельзя умножать на 0?
Это нельзя отменить: 2x + y = 5 превратится в 0 = 0, и условие пропадёт. Система {x + y = 2, x − y = 0} имеет одно решение (1; 1), а после «×0» останется только x + y = 2 — бесконечно много решений. Ответ испортился.
Запоминалка
«Минус жертва на ступеньку»: k = −(убиваемое)/(ступенька). Ставь наверх строку со ступенькой ±1 — тогда без дробей.

Ранг матрицы

Простыми словами

Ранг — сколько в матрице «по-настоящему разных» строк, т.е. таких, которые нельзя получить из других. Считаем так: приводим к ступенчатому виду (тем же Гауссом) и считаем ненулевые строки.

Пример: у ранг 1 — вторая строка = 2 × первая.

Почему ранг не меняется от преобразований
Все три действия П-У-П можно отменить — «новой информации» не появляется и старая не теряется. А «лишние» строки (суммы других) при вычитании превращаются в нули — так мы их и находим.
Полезно знать
rg A ≤ min(строк, столбцов). У 3×2 ранг не больше 2. В задачах с параметром делить на α можно только если α ≠ 0 — случай α = 0 разбирай отдельно.
Без дробей: Сi → p·Сi − a·С1 (умножение строки на p ≠ 0 разрешено).

Сколько решений: Кронекер–Капелли. Однородные системы

Простыми словами

r — ранг матрицы коэффициентов, r̄ — ранг расширенной (с правыми частями), n — число неизвестных.

r ≠ r̄решений нет: появилась строка 0 0 … 0 | b (b ≠ 0), то есть «0 = b»
r = r̄ = nровно одно решение: у каждой неизвестной своя ступенька
r = r̄ < nбесконечно много: n − r переменных свободные (любые числа t, v…)
Откуда это
После прямого хода каждая ненулевая строка — «настоящее» уравнение. Строка «0 = 5» неверна ни при каких x → решений нет. Если противоречий нет, каждая ступенька «привязывает» одну переменную. Переменные без ступенек ничем не привязаны → их можно брать любыми → решений бесконечно много.
Однородные системы A·X = 0
Все правые части — нули. Такая система всегда имеет решение X = 0 (подставь — получится 0 = 0). Ненулевые решения есть ⇔ r < n (для квадратной: ⇔ |A| = 0).
Если X₁ и X₂ — решения, то X₁ + X₂ и α·X₁ — тоже решения: A(X₁ + X₂) = 0 + 0 = 0.
Запоминалка
«Ранги равны — решения есть. Ступенек столько, сколько неизвестных, — одно, меньше — бесконечно. Ноль равно пяти — решений нет.»
